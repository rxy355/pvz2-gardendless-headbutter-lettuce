# 奶油生菜 · PvZ2 Gardendless

模组版本 **3.4.1**，适用于 **PvZ2 Gardendless 0.16.15（GP-Next 1.5.8）**。

## 下载

下载本仓库中的 [`HeadbutterLettuce-Gardendless-0.16.15.zip`](./HeadbutterLettuce-Gardendless-0.16.15.zip)。压缩包包含模组说明和三个可导入的组件包。

## 安装

1. 在游戏中按 **F9** 打开 GP-Next，并启用 JavaScript Mod。
2. 按顺序导入压缩包内的 `1-pvzge.entities.zip`、`2-gzh.headbutter.zip`、`3-gzh.headbutter.content.zip`。若已启用相同版本的官方实体框架，可从第二个包开始。
3. 启用三个包并重启游戏。普通关卡可在 F9 的奶油生菜控制面板中解锁植物。
4. 可在模组设置中切换原版紫叶装扮。

完整安装说明、数值和机制细节见下载包内的 `README.md`。
