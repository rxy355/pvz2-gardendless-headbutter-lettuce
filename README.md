# 奶油生菜 · PvZ2 Gardendless

模组版本为 **3.4.4**，适用于 **PvZ2 Gardendless 0.16.15（GP-Next 1.5.8）**。

## 安装与使用

按以下步骤导入组件包。

1. 进入游戏，按 **F9** 打开 GP-Next，在 Mod 管理中启用 JavaScript Mod。
2. 依次导入 `1-pvzge.entities.zip`、`2-gzh.headbutter.zip`、`3-gzh.headbutter.content.zip`。如果已经启用了相同版本的官方实体框架，可从第二个包开始导入。
3. 启用三个包，重新启动游戏。沙盒选卡中可直接选用奶油生菜。
4. 普通关卡可在进入玩家存档后，通过 F9 的奶油生菜控制面板点击 **解锁奶油生菜**。重新进入可自由选卡的关卡后即可选择。

默认使用国际版的绿叶外观。要使用原版紫叶装扮，按 F9，打开 **奶油生菜 · 原版机制** 的模组设置并启用 **紫叶装扮**。卡图和拖动预览会切换到紫叶外观，场上植物在开始下一段动画时切换。

## 固定数值

| 项目 | 数值 |
| --- | --- |
| 阳光、冷却 | 175、7 秒 |
| 生命 | 900 |
| 普通头槌 | 100，在植物前后固定判定范围内攻击同排单个目标 |
| 普通黄油 | 初始触发概率为 10%，每次发射后重置为 10%。连续未投出时，下一次攻击的概率逐次提高，第一次未投出后约为 11.41% |
| 黄油命中 | 40 伤害，定身 8 秒 |
| 能量豆 | 3 轮，每轮开始向全场有效目标投掷最多 3 块黄油，并造成同排近身范围伤害 150 |

普攻触发黄油时，附近有 1 至 3 只有效僵尸就各投 1 块，有 4 只就随机投 3 至 4 块，有 5 只或更多就随机投 3 至 5 块。同一轮的每块黄油瞄准不同的僵尸，同排可以选中多只。

两种外观共用同一套机制。

## 资源与验证

- 植物本体、紫叶装扮、左右头槌特效、黄油飞溅及音效取自国际版 13.5.2 资源。保留待机变体、左右攻击、能量豆起手／循环／收尾、浇水动画和原始图层顺序。
- 选卡界面和战斗卡槽使用国际版种子包图集里的奶油生菜静态卡图。紫叶卡图叠加原版扮装叶片。拖动预览和格子上的落点预览采用与落地植物相同的尺寸。
- 逐帧校验原版 PAM 与 DragonBones 的可见图层、排序及变换。录屏中约 35.8–36.3 秒的前向头槌可用于对照甩头、伏地及起身露出眼睛的过程。
- 用 Gardendless 0.16.15 实测左右头槌、黄油命中、能量豆三轮与装扮切换。黄油按原版抛物线公式换算。对同排普通僵尸的实测弧顶，普攻约 2.50 格，能量豆约 2.35 格。
- 以录屏的草坪格宽校准战场本体和头槌特效。两者比 3.2.0 放大约 26%，并分别校准脚点和命中特效落点。特效固定在植物两侧，打空时也播放。
- 大招三轮各结算一次范围伤害。同排无甲目标若三轮都在范围内，基础范围伤害共 450。若它也在同一侧三次被头槌选中，直接伤害共 750。黄油命中伤害另计。范围伤害会乘上战场伤害倍率。
- 大招每轮随机选取射程内、本次大招尚未向其发射黄油的僵尸，空余名额按棋盘顺序补选有效墓碑。整轮没有新候选时才清空记录并重新选取。已选目标若因未来僵尸护盾等原因无法发射，该轮会空出该名额。
- 大招黄油在起飞时按僵尸走速预测横向落点，墓碑用格心。飞行中保留原定轨迹，并按原版碰撞框换算后的尺寸检测命中。
- 大招收尾开始时立即恢复普通索敌。有目标时下一帧即可接头槌，空场时完整播放收尾。
- 机制依据国际版 13.5.2 APK 的数据和指令，并在 Gardendless 实测。特殊僵尸和场景道具的碰撞仍需与国际版实机对照。
