# 奶油生菜 · PvZ2 Gardendless

模组版本 **3.4.2**，适用于 **PvZ2 Gardendless 0.16.15（GP-Next 1.5.8）**。

## 下载

- [v3.4.2 模组包](./HeadbutterLettuce-Gardendless-0.16.15-v3.4.2.zip)
- [v3.4.2 Release 页面](./releases/tag/v3.4.2)

压缩包内包含安装说明和三个可导入组件包。

## 安装

1. 在游戏中按 **F9** 打开 GP-Next，并启用 JavaScript Mod。
2. 按顺序导入包内的 `1-pvzge.entities.zip`、`2-gzh.headbutter.zip`、`3-gzh.headbutter.content.zip`。若已启用相同版本的官方实体框架，可从第二个包开始。
3. 启用三个包并重启游戏。普通关卡可在 F9 的奶油生菜控制面板中解锁植物。
4. 可在模组设置中切换原版紫叶装扮。

普通攻击未投出黄油时，下一次攻击的概率会递增；实际投出后重置。概率曲线按长期期望每 10 次攻击投出 1 次校准。完整数值、机制及装扮说明见模组包内 `README.md`。
